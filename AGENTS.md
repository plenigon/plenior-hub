# AGENTS.md

Instructions for coding agents. Humans and agents follow the same rules in
[`CONTRIBUTING.md`](CONTRIBUTING.md); this file only adds what an agent needs.

- Run `scripts/gate.sh` from the repository root before proposing a change.
- Do not change or delete a test to make the gate pass.
- Never put a secret, credential, or customer payload in the repository or in
  a prompt.
- One task, one branch, one pull request.
