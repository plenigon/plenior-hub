# Security policy

## Reporting a vulnerability

Report vulnerabilities privately to the maintainer,
[@caiopieri](https://github.com/caiopieri), through GitHub. Do not open an issue
or a pull request that describes the vulnerability.

Do not include a secret, a credential, or a customer payload in the report.
Include the affected component, the steps to reproduce, and the impact you
observed.

## Supported versions

Only the latest commit on `main` receives security fixes until the first
tagged release.
